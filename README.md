# 🌤️ Weather App

A simple and responsive Weather Web App built using Flask, HTML, CSS, and OpenWeather API.

## 🚀 Features
- 🌍 Search weather by city
- 📍 Get weather using current location
- 📆 5-day forecast
- 📊 Temperature chart
- 🌙 Dark mode

## 🛠️ Technologies Used
- Python (Flask)
- HTML, CSS, JavaScript
- OpenWeather API
- Chart.js

## ▶️ How to Run
1. Install dependencies:
   pip install 

2. Run the app:
   python app.py

3. Open in browser:
   http://127.0.0.1:5000
